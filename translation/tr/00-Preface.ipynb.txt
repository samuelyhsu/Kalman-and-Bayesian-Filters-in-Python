## 卡尔曼滤波器与贝叶斯滤波器

传感器是有噪声的。世界上充满了我们想要测量和跟踪的数据与事件，但我们不能指望传感器给出完美的信息。我车里的 GPS 会报告海拔高度，每次我经过道路上的同一个位置，它报告的海拔都略有不同。我的厨房秤对同一个物体称两次，读数也会不同。

在简单的情形下，解决办法显而易见。如果秤的读数略有差异，我可以多读几次取平均值，或者换一个更准确的秤。但如果传感器噪声非常大，或者环境使数据采集变得困难，又该怎么办呢？我们可能要跟踪一架低空飞行的飞机，可能想为无人机创建自动驾驶仪，或者想确保我们的农用拖拉机播种了整块田地。我从事计算机视觉工作，需要在图像中跟踪运动物体，而计算机视觉算法给出的结果噪声很大、并不可靠。

本书将教你如何解决这类滤波问题。我会用到许多不同的算法，但它们都基于*贝叶斯概率*。简单来说，贝叶斯概率是根据过去的信息来判断什么情况可能为真。

如果我问你我的车此刻的朝向是多少，你会毫无头绪。你只能报出一个 1$^\circ$ 到 360$^\circ$ 之间的数，猜中的概率只有 360 分之一。现在假设我告诉你，2 秒钟之前它的朝向是 243$^\circ$。2 秒内我的车不可能转很大的弯，所以你可以做出准确得多的预测。你是在利用过去的信息，更准确地推断现在或未来的信息。

世界也是有噪声的。这个预测帮助你做出更好的估计，但它同样受噪声影响。我可能刚刚为了躲一只狗而刹车，或者绕开了一个坑洼。强风和路面结冰是影响我的车行驶路径的外部因素。在控制领域的文献中我们把这称为*噪声*，尽管你可能并不这样看待它。

贝叶斯概率还有更多内容，但你已经抓住了主要思想：知识是不确定的，我们根据证据的强度来调整自己的信念。卡尔曼滤波器与贝叶斯滤波器把我们对系统行为的有噪声、有限的了解，与有噪声、有限的传感器读数融合起来，得到对系统状态的最佳估计。我们的原则是绝不丢弃信息。

假设我们正在跟踪一个物体，传感器报告它突然改变了方向。它真的转向了，还是数据有噪声？这要视情况而定。如果这是一架喷气式战斗机，我们会非常倾向于相信它做了突然机动的报告。如果这是直线轨道上的一列货运火车，我们就会对这个报告打折扣。我们还会根据传感器的精度进一步修正自己的信念。我们的信念取决于过去、取决于我们对被跟踪系统的了解，也取决于传感器的特性。

卡尔曼滤波器由鲁道夫·埃米尔·卡尔曼（Rudolf Emil Kálmán）发明，用来以数学上最优的方式解决这类问题。它最初用于阿波罗登月任务，此后被应用于极其广泛的领域。飞机上有卡尔曼滤波器，潜艇上有，巡航导弹上也有。华尔街用它们来跟踪市场。它们被用于机器人、物联网（IoT）传感器和实验室仪器。化工厂用它们来控制和监测反应。它们被用于医学成像，以及消除心电信号中的噪声。只要涉及传感器和/或时间序列数据，通常就会用到卡尔曼滤波器或与之相近的滤波器。

## 写作本书的动机

我是一名软件工程师，在航空航天领域工作了近二十年，因此一直与卡尔曼滤波器“擦肩而过”，却从未亲自实现过。它们一直以难学而令人生畏。其理论很美，但如果你还没有接受过信号处理、控制理论、概率与统计以及制导与控制理论等主题的良好训练，学起来相当困难。当我转向用计算机视觉解决跟踪问题时，自己动手实现它们的需求变得迫切起来。

这个领域有一些出色的教材，例如 Grewal 和 Andrews 的 *Kalman Filtering*。但如果你没有必要的背景知识，坐下来读其中许多书是一种令人沮丧且备受煎熬的体验。通常前几章会飞快地掠过好几年的本科数学，轻描淡写地让你去参考伊藤（Itō）微积分的教科书，并用寥寥几段话呈现整整一学期的统计学内容。它们是高年级本科或研究生课程的教材，也是研究人员和专业人士的宝贵参考书，但对于更随意的读者来说，读起来确实十分艰难。符号不加解释地引入，不同的书对同一个概念使用不同的词汇和变量名，而且这些书几乎没有例子或习题解答。我常常发现自己能看懂一个定义的文字、理解其中的数学，却不知道这些文字和数学试图描述的是什么现实世界现象。“可这到底是什么*意思*？”是我反复出现的念头。下面是曾经让我困惑不已的典型例子：

$$\begin{aligned}\hat{x}_{k} = \Phi_{k}\hat{x}_{k-1} + G_k u_{k-1} + K_k [z_k - H \Phi_{k} \hat{x}_{k-1} - H G_k u_{k-1}]
\\
\mathbf{P}_{k\mid k} = (I - \mathbf{K}_k \mathbf{H}_{k})\textrm{cov}(\mathbf{x}_k - \hat{\mathbf{x}}_{k\mid k-1})(I - \mathbf{K}_k \mathbf{H}_{k})^{\text{T}}  + \mathbf{K}_k\textrm{cov}(\mathbf{v}_k )\mathbf{K}_k^{\text{T}}\end{aligned}$$

然而，当我终于开始理解卡尔曼滤波器时，我意识到其背后的概念相当直白。只要你知道几条简单的概率规则，并对我们如何融合不确定的知识有一些直觉，卡尔曼滤波器的概念就是可以理解的。卡尔曼滤波器以难学著称，但剥去大量形式化的术语之后，这门学问及其数学之美在我面前清晰地展现出来，我爱上了这个主题。

当我开始理解数学和理论之后，更多的困难又出现了。书或论文会陈述某个事实，并给出一张图作为证明。可惜，为什么这个陈述成立我并不清楚，或者我无法复现那张图。或者我会想：“如果 R=0，这还成立吗？”又或者作者给出的伪代码层次太高，以至于实现方式并不明显。有些书提供 Matlab 代码，但我没有那个昂贵软件包的许可证。最后，许多书在每章末尾都给出许多有用的习题。如果你想自己实现卡尔曼滤波器，这些习题是你需要理解的，但这些习题没有答案。如果你是在课堂上使用这本书，也许还说得过去，但对自学的读者来说这糟透了。我讨厌作者对我隐瞒信息，大概是为了避免课堂上的学生“作弊”。

所有这些都妨碍了学习。我想跟踪屏幕上的一幅图像，或者为我的 Arduino 项目写点代码。我想知道书中的图是怎么画出来的，并选择与作者不同的参数。我想运行仿真。我想向信号中注入更多噪声，看看滤波器表现如何。在日常代码中使用卡尔曼滤波器的机会成千上万，而这个相当直白的主题却成了火箭科学家和学者的专属领地。

我写这本书就是为了满足所有这些需求。如果你设计军用雷达，这本书不会是你唯一需要的书。去一所顶尖的理工科院校攻读硕士或博士学位吧，因为你会需要它。本书面向业余爱好者、好奇的人，以及需要对数据进行滤波或平滑的在职工程师。如果你是业余爱好者，这本书应该能提供你需要的一切。如果你认真对待卡尔曼滤波器，你还需要更多。我的目的是介绍足够多的概念和数学，使教科书和论文变得可以读懂。

本书是交互式的。虽然你可以把它当作静态内容在线阅读，但我强烈建议你按其本来的用法使用它。它是用 Jupyter Notebook 写成的，使我能把文字、数学、Python 以及 Python 的输出整合在一处。本书中的每一张图、每一份数据都是由 notebook 内部的 Python 生成的。想把某个参数的值加倍？只需修改参数值，然后按 CTRL-ENTER，新的图或打印输出就会出现。

本书有习题，同时也有答案。我信任你。如果你只是需要一个答案，尽管去读答案。如果你想把这些知识内化，请在读答案之前先尝试自己实现这道习题。由于本书是交互式的，你可以在书中直接输入并运行你的解答——无需切换到别的环境，也不必在开始前先导入一堆东西。

本书是免费的。我在卡尔曼滤波的书籍上花了几千美元。我无法相信它们对于经济不景气地区的人，或者经济拮据的学生来说是负担得起的。我从 Python 这样的自由软件，以及 Allen B. Downey 那样的免费书籍 [1] 中获益良多。是时候回报了。所以，本书是免费的，托管在 GitHub 的免费服务器上，并且只使用 IPython 和 MathJax 等免费开源的软件。

## Jupyter

首先，说几句关于在本书中使用 Jupyter Notebook 的话。本书是交互式的。如果你想运行代码示例，尤其是想看到动画图，就需要运行代码单元格。我无法教会你关于 Jupyter Notebook 的一切，不过有几件事常让读者犯难。你可以访问 http://jupyter.org/ 查看详细文档。

第一，你必须始终运行最上方的那个代码单元格，也就是带有注释 `#format the book` 的那个，它就在正上方。它不仅仅是设置格式（你可能并不在意格式），还会加载一些必要的模块，并对绘图和打印做一些全局设置。所以，除非你只是被动阅读，否则请始终运行这个单元格。

这一行

```python
%matplotlib inline
```
会让图在 notebook 内部显示。Matplotlib 是一个绘图包，下面会介绍。出于我不理解的原因，Jupyter Notebook 的默认行为是在外部窗口中生成图。

`%matplotlib` 中的百分号用于 IPython 的*魔术命令*（magic）——这些是给内核的命令，用来做一些不属于 Python 语言本身的事情。有许多有用的魔术命令，你可以在这里了解它们：http://ipython.readthedocs.io/en/stable/interactive/magics.html

运行单元格里的代码很容易。点击它使其获得焦点（周围会画出一个方框），然后按 CTRL-Enter。

第二，单元格必须按顺序运行。我把问题分散在几个单元格中；如果你试图直接跳到下面去运行第十个代码单元格，几乎肯定不会成功。如果你还没有运行过任何东西，只需从 **Cell** 菜单中选择 *Run All Above*。这是确保所有单元格都已运行的最简单方法。

单元格运行过一遍之后，你通常可以跳来跳去，以不同的顺序重新运行，但并不总是可行。我正在努力修复这一点，但这里存在取舍。比如，我会在第 10 个单元格中定义一个变量，然后在第 11 和第 12 个单元格中运行修改该变量的代码。如果你回头再次运行第 11 个单元格，变量的值将是第 12 个单元格设置的值，而代码期望的是第 10 个单元格设置的值。所以，如果你乱序运行单元格，偶尔会得到奇怪的结果。我的建议是稍微回退一点，再按顺序运行单元格，回到正确的状态。这很烦人，但 Jupyter notebook 的交互性足以弥补这一点。更好的做法是在 GitHub 上提交 issue，让我知道这个问题并修复它！

最后，有些读者报告说，在某些浏览器中动画绘图功能有问题。我无法复现。在书的某些部分，我使用了 `%matplotlib notebook` 魔术命令，它启用交互式绘图。如果这些图对你不起作用，可以尝试把它改成 `%matplotlib inline`。你会失去动画绘图，但它似乎在所有平台和浏览器上都能工作。

现在来绘制一些数据。大体上这非常简单。Matplotlib 包含绘图库 `pyplot`。业界标准是把它导入为 `plt`。导入后，用一个数字列表或数组调用 `plt.plot` 即可绘制这些数字。如果多次调用，它会绘制多个数据系列，每个系列使用不同的颜色。
=====CELL 47=====
输出 `[<matplotlib.lines.Line2D at 0x2ba160bed68>]` 是因为 `plt.plot` 会返回刚刚创建的对象。通常我们不想看到它，所以我在最后一个绘图命令后加上 `;` 来抑制该输出。

默认情况下，`plot` 假定 x 序列以 1 递增。你可以同时传入 x 和 y 来提供你自己的 x 序列。

## 关于 Python 和数学编码的思考
=====CELL 59=====
大多数卡尔曼滤波和其他工程类教材都是由数学家或学者写的。当有软件时（很少见），它也不是生产级质量的。以 Paul Zarchan 的 *Fundamentals of Kalman Filtering* 为例。这是一本很棒的书，值得放进你的藏书里，也是少数为每个例子和图表都提供完整源代码的书之一。但代码是 Fortran，除了对 `MATMUL` 之类函数的调用之外没有任何子程序。卡尔曼滤波器在全书中被反复重新实现。同一份代码清单把仿真与滤波代码混在一起，很难区分它们。有些章节以略有不同的方式实现同一个滤波器，并用粗体文字突出显示改动的那几行。如果需要龙格-库塔法，它就嵌在代码里，也没有注释。

有更好的办法。如果我想执行龙格-库塔法，我会调用 `ode45`，而不会把龙格-库塔的实现嵌入我的代码。我不想多次实现龙格-库塔法，也不想多次调试它。如果我确实发现了 bug，我可以只修复一次，并确保它现在在我所有不同的项目中都能工作。而且，它是可读的。我很少关心龙格-库塔法的实现。

这是一本关于卡尔曼滤波的教材，你可以争辩说我们*确实*关心卡尔曼滤波器的实现。这没错，但执行滤波的代码只有大约 10 行。实现这些数学的代码相当简单。卡尔曼滤波器所需的大部分工作，是设计送入数学引擎的那些矩阵。

一个可能的缺点是，执行滤波的方程被隐藏在函数之后，有人可能会说这在教学性的文本中是一种损失。我的看法恰恰相反。我想让你学会如何在现实世界、在真实项目中使用卡尔曼滤波器，而你不应该到处复制粘贴已有的算法。

我使用 Python 类。我使用类主要是为了组织滤波器所需的数据，而不是为了实现继承等面向对象（OO）特性。例如，`KalmanFilter` 类存储名为 `x`、`P`、`R`、`Q`、`S`、`y`、`K` 的矩阵和向量。我见过卡尔曼滤波器的过程式库，它们要求程序员自己维护所有这些矩阵。对于玩具程序来说，这也许还不算太糟，但如果要编写一组卡尔曼滤波器，你就不会乐于去管理所有这些矩阵和其他相关数据了。我在自己的工作中偶尔会从这些类派生，觉得很方便，但我不想强迫人们使用 OO，因为我知道很多人不喜欢它。
