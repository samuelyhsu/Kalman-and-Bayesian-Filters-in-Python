# 一维卡尔曼滤波器
=====CELL 4=====
现在我们已经理解了离散贝叶斯滤波器和高斯分布，可以着手实现卡尔曼滤波器了。我们将完全按照实现离散贝叶斯滤波器的方式来做——不是从方程开始，而是基于对问题的推理，一步步地发展出代码。

“一维”意味着这个滤波器只跟踪一个状态变量，例如 x 轴上的位置。在后续的章节中，我们将学习更一般的多维形式的滤波器，它可以同时跟踪许多状态变量，例如位置、速度和加速度。回想一下，我们在 g-h 滤波器中使用速度，得到了比只跟踪位置更好的估计。卡尔曼滤波器也是如此。

那么，为什么不直接跳到多维形式的滤波器呢？说实话，那里的数学很难，而我用来发展滤波器的直觉方法也开始失效。这些数学会掩盖让卡尔曼滤波器得以工作的那些相当简单的原理。

所以，在本章中我们学习如何用高斯分布来实现贝叶斯滤波器。卡尔曼滤波器就是这么一回事——一个使用高斯分布的贝叶斯滤波器。在下一章我们将切换到多维形式，卡尔曼滤波器的全部威力将得以释放！

## 问题描述

和**离散贝叶斯滤波器**一章一样，我们将在工作场所的一条长走廊中跟踪一个移动的对象。假设在我们最近的一次黑客马拉松上，有人做出了一个 RFID 追踪器，它能给出狗的相当准确的位置。传感器返回狗到走廊左端的距离，单位为米。所以，23.4 就表示狗距离走廊左端 23.4 米。

这个传感器并不完美。23.4 的读数可能对应于狗在 23.7 或 23.0 的位置。然而，它极不可能对应于 47.6 的位置。黑客马拉松期间的测试证实了这个结果——传感器“相当”准确，虽然有误差，但误差很小。此外，误差似乎均匀地分布在真实位置的两侧；23 米的位置被测成 22.9 或 23.1 的可能性相同。也许我们可以用高斯分布来对此建模。

我们预测狗在移动。这个预测并不完美。有时我们的预测会偏多，有时会偏少。我们更可能只偏多或偏少一点点，而不是很多。也许我们同样可以用高斯分布来对此建模。

## 用高斯概率进行跟踪

离散贝叶斯滤波器使用概率直方图来跟踪狗。直方图中的每个柱子代表一个位置，其值是狗处于该位置的概率。

跟踪是通过预测和更新的循环来完成的。我们使用了方程

$$\begin{aligned}
\bar {\mathbf x} &= \mathbf x \ast f_{\mathbf x}(\bullet)\, \, &\text{Predict} \\
\mathbf x &= \mathcal L \cdot \bar{\mathbf x}\, \, &\text{Update}
\end{aligned}$$

来计算新的概率分布。回想一下，$\bar{\mathbf x}$ 是*先验*，$\mathcal L$ 是在给定先验 $\bar{\mathbf x}$ 的情况下测量值的*似然*，$f_{\mathbf x}(\bullet)$ 是*过程模型*，$\ast$ 表示*卷积*。$\mathbf x$ 用粗体表示它是一个数字的直方图，即向量。

这种方法有效，但产生的直方图暗示狗可能同时在多个地方。而且，对于大问题，计算非常慢。

我们能否把直方图 $\mathbf x$ 换成高斯分布 $\mathcal N(x, \sigma^2)$？当然可以！我们已经学会了如何把置信度表示为高斯分布。一个高斯分布，也就是单个数对 $\mathcal N(\mu, \sigma^2),$，可以取代整个概率直方图：
=====CELL 13=====
我希望你能看到这其中的威力。我们可以用一对数字取代成百上千个数字：$x = \mathcal N(\mu, \sigma^2)$。

高斯分布的尾部向两侧延伸到无穷远，所以它涵盖了直方图中任意多个柱子。如果它代表我们对狗在走廊中位置的置信度，那么这一个高斯分布覆盖了整条走廊（以及该轴上的整个宇宙）。我们认为狗很可能在 10 处，但它也可能在 8、14，或者以无穷小的概率出现在 10$^{80}$ 处。

在本章中，我们用高斯分布取代直方图：

$$\begin{array}{l|l|c}
\text{discrete Bayes} & \text{Gaussian} & \text{Step}\\
\hline
\bar {\mathbf x} = \mathbf x \ast f(\mathbf x) &
\bar {x}_\mathcal{N} =  x_\mathcal{N} \, \oplus \, f_{x_\mathcal{N}}(\bullet) &
\text{Predict} \\
\mathbf x = \|\mathcal L \bar{\mathbf x}\| & x_\mathcal{N} = L \, \otimes \, \bar{x}_\mathcal{N} & \text{Update}
\end{array}$$

其中 $\oplus$ 和 $\otimes$ 是用来表示某种尚未确定的、作用于高斯分布的运算符。在本书的其余部分我不会这样写，但这个下标表示 $x_\mathcal{N}$ 是一个高斯分布。

离散贝叶斯滤波器用卷积来做预测。我们证明过它使用了*全概率定理*，即通过求和来计算，所以也许我们可以把高斯分布相加。它用乘法把测量值纳入先验，所以也许我们可以把高斯分布相乘。难道真的这么简单：

$$\begin{aligned}
\bar x &\stackrel{?}{=} x + f_x(\bullet) \\
x &\stackrel{?}{=} \mathcal L \cdot \bar x
\end{aligned}$$

只有当两个高斯分布的和与积仍然是高斯分布时，这才行得通。否则，在第一个历元之后 $x$ 就不再是高斯分布，这个方案就崩溃了。

## 用高斯分布做预测

我们使用牛顿运动方程，根据当前速度和先前位置来计算当前位置：

$$ \begin{aligned}\bar{x}_k &= x_{k-1} + v_k \Delta t \\
 &= x_{k-1} + f_x\end{aligned}$$

我把记号 $f_x(\bullet)$ 简写成 $f_x$，以保持方程简洁。

如果狗在 10 米处，速度是 15 米/秒，历元长 2 秒，那么我们有

$$ \begin{aligned} f_x &= v\Delta t = 15\cdot 2\\
\bar{x}_k &= 10 + (15\cdot 2) = 40 \end{aligned}$$

我们对它当前的位置和速度是不确定的，所以这样不行。我们需要用高斯分布来表达不确定性。

位置很容易。我们把 $x$ 定义为一个高斯分布。如果我们认为狗在 10 米处，我们的不确定性的标准差是 0.2 米，那么得到 $x=\mathcal N(10, 0.2^2)$。

那么我们对它运动的不确定性呢？我们把 $f_x$ 定义为一个高斯分布。如果狗的速度是 15 米/秒，历元是 1 秒，我们的不确定性的标准差是 0.7 米/秒，那么得到 $f_x = \mathcal N (15, 0.7^2)$。

先验的方程是

$$\bar x = x + f_x$$

两个高斯分布的和是什么？在上一章中我证明了：

$$\begin{gathered}
\mu = \mu_1 + \mu_2 \\
\sigma^2 = \sigma^2_1 + \sigma^2_2
\end{gathered}$$

这是个绝佳的消息；两个高斯分布之和仍是高斯分布！

数学上行得通，但这在直觉上说得通吗？想想这个抽象方程的物理含义。我们有

$$\begin{gathered}
x=\mathcal N(10, 0.2^2)\\
f_x = \mathcal N (15, 0.7^2)
\end{gathered}$$

如果我们把它们相加，得到：

$$\begin{aligned}\bar x &= \mu_x + \mu_{f_x} = 10 + 15 &&= 25 \\
\bar\sigma^2 &= \sigma_x^2 + \sigma_{f_x}^2 = 0.2^2 + 0.7^2 &&= 0.53\end{aligned}$$

预测位置等于先前位置加上移动量，这说得通。那方差呢？对此更难形成直觉。然而，回想一下，对于离散贝叶斯滤波器的 `predict()` 函数，我们总是会丢失信息。我们并不真正知道狗要往哪里移动，所以置信度应该变小（方差变大）。$\sigma_{f_x}^2$ 是由于对运动的不完美预测而加入系统的不确定性的量，所以我们把它加到现有的不确定性上。

让我们利用 Python `collection` 模块中的 `namedtuple` 类来实现一个高斯对象。我们可以用元组来实现高斯分布，其中 $\mathcal N(10, 0.04)$ 在 Python 中实现为 `g = (10., 0.04)`。我们用 `g[0]` 访问均值，用 `g[1]` 访问方差。

`namedtuple` 的工作方式与元组相同，只不过你要给它提供一个类型名和字段名。这不重要，但我修改了 `__repr__` 方法，使其用本章中的记号来显示它的值。

## 用高斯分布做更新

离散贝叶斯滤波器用概率直方图来编码我们对狗位置的置信度。这个分布是离散的、多峰的。它可以表达狗同时在两个位置的强置信度，而且这些位置是离散的。

我们提议用高斯分布取代直方图。离散贝叶斯滤波器用这段代码来计算后验：


```python
def update(likelihood, prior):
    posterior = likelihood * prior
    return normalize(posterior)
```

它是下面这个方程的实现：

$$x = \| \mathcal L\bar x \|$$

我们刚刚已经证明，可以用高斯分布来表示先验。那似然呢？似然是在给定当前状态的情况下测量值的概率。我们已经学会了如何把测量值表示为高斯分布。例如，也许我们的传感器说狗在 23 米处，标准差为 0.4 米。我们的测量值表示为似然，就是 $z = \mathcal N (23, 0.16)$。

似然和先验都用高斯分布建模。我们能把高斯分布相乘吗？两个高斯分布的乘积还是高斯分布吗？

前一个问题的答案是肯定的，后一个问题则几乎是。在上一章中我证明了两个高斯分布的乘积与另一个高斯分布成正比。

$$\begin{aligned}
\mu &= \frac{\sigma_1^2 \mu_2 + \sigma_2^2 \mu_1} {\sigma_1^2 + \sigma_2^2}, \\
\sigma^2 &= \frac{\sigma_1^2\sigma_2^2}{\sigma_1^2+\sigma_2^2}
\end{aligned}$$

我们可以立刻推断出几件事。如果我们对结果做归一化，乘积就是另一个高斯分布。如果一个高斯分布是似然，第二个是先验，那么均值就是先验和测量值的加权和。方差是先验方差和测量方差的某种组合。最后，方差完全不受均值的值影响！

我们用贝叶斯的术语这样表示：

$$\begin{aligned}
\mathcal N(\mu, \sigma^2) &= \| prior \cdot likelihood \|\\
&= \| \mathcal{N}(\bar\mu, \bar\sigma^2)\cdot \mathcal{N}(\mu_z, \sigma_z^2) \|\\
&= \mathcal N(\frac{\bar\sigma^2 \mu_z + \sigma_z^2 \bar\mu}{\bar\sigma^2 + \sigma_z^2},\frac{\bar\sigma^2\sigma_z^2}{\bar\sigma^2 + \sigma_z^2})
\end{aligned}$$

如果我们在一个函数 `gaussian_multiply()` 中实现它，就可以把滤波器的更新步骤实现为
=====CELL 27=====
如果我们使用更具体的名字，也许会更清楚：

```python
def update_dog(dog_pos, measurement):
    estimated_pos = gaussian_multiply(measurement, dog_pos)
    return estimated_pos
```

这样不那么抽象，也许有助于理解，但这是糟糕的编码实践。我们编写的是一个适用于任何问题的卡尔曼滤波器，而不仅仅是跟踪走廊里的狗，所以我们不会使用带有“dog”的变量名。而且，这种形式掩盖了我们是在把似然乘以先验这一事实。

我们已经实现了滤波器的大部分，但我担心这一步仍然有点让人困惑。我断言我们可以把高斯分布相乘，并且这正确地执行了更新步骤，但为什么这是对的？让我们绕个弯，花些时间来乘一乘高斯分布。

把这两个高斯分布看作两次测量。如果我测量两次，每次都得到 10 米，我应该得出结论：长度接近 10 米。因此均值应该是 10。断定长度实际上是 11 或 9.5 是没有意义的。而且，两次测量比一次测量让我更有把握，所以结果的方差应该更小。

“量两次，切一次”是一句众所周知的谚语。高斯乘法就是这一物理事实的数学模型。

如果你请两个人测量桌子到墙的距离，一个人得到 10.2 米，另一个人得到 9.7 米，那么如果你对两人的技能同样信任，你最好的猜测必然是平均值，9.95 米。

回想一下 g-h 滤波器。我们曾一致认为，如果我在两个秤上称体重，第一个读数是 160 磅，第二个是 170 磅，并且两个秤同样准确，那么最好的估计就是 165 磅。此外，相比 160 磅或 170 磅，我应该对 165 磅更有把握一些，因为我现在有两个读数，它们都接近这个估计值，这增强了我的信心：两者都不至于错得离谱。

在更复杂的情况下，这会变得违反直觉，所以让我们进一步考虑。也许更合理的假设是其中一个人犯了错误，真实距离要么是 10.2，要么是 9.7，但肯定不是 9.95。这当然是可能的。但我们知道我们的测量是有噪声的，所以我们没有理由认为其中一个测量没有噪声，或者某个人犯了严重错误因而可以丢弃他的测量。根据所有可用的信息，最好的估计必然是 9.95。

在卡尔曼滤波器的更新步骤中，我们组合的不是两个测量值，而是一个测量值和先验，即纳入测量值之前的估计。我们在 g-h 滤波器中已经推导过这个逻辑。无论我们是在纳入来自两个测量值的信息，还是一个测量值和一个预测，数学都是一样的。

## 代码讲解

现在让我们逐步讲解代码。

```python
process_var = 1.
sensor_var = 2.
```

这些是过程模型和传感器的方差。传感器方差的含义应该很清楚——它是每次测量中存在多大的方差。过程方差是过程模型中有多大的误差。我们预测在每个时间步狗向前移动一米。狗很少会按我们预期的去做，而且像山坡或松鼠的气味这样的东西都会改变它的行进。如果这是一个响应数字指令的机器人，性能会好得多，方差也许是 $\sigma^2=.05$。这些不是“魔法”数字；方差的平方根是以米为单位的距离误差。只要把数字填进去，就很容易让卡尔曼滤波器工作起来，但如果这些数字不能反映现实，滤波器的性能就会很差。

```python
x = gaussian(0., 20.**2)
```

这是用高斯分布表示的狗的初始位置。位置是 0 米，方差为 400 m$^2$，即标准差为 20 米。你可以把它理解为在说“我以 99.7% 的精度相信位置是 0 加减 60 米”。这是因为对于高斯分布，约 99.7% 的值落在均值的 $\pm3\sigma$ 之内。


## 卡尔曼增益

我们看到滤波器是有效的。现在让我们回到数学，去理解发生了什么。后验 $x$ 计算为似然乘以先验 ($\mathcal L \bar x$)，两者都是高斯分布。

因此后验的均值由下式给出：

$$
\mu=\frac{\bar\sigma^2\, \mu_z + \sigma_z^2 \, \bar\mu} {\bar\sigma^2 + \sigma_z^2}
$$

我用下标 $z$ 表示测量值。我们可以把它改写为：

$$\mu = \left( \frac{\bar\sigma^2}{\bar\sigma^2 + \sigma_z^2}\right) \mu_z + \left(\frac{\sigma_z^2}{\bar\sigma^2 + \sigma_z^2}\right)\bar\mu$$

在这种形式下，很容易看出我们是用权重对测量值和先验做缩放：

$$\mu = W_1 \mu_z + W_2 \bar\mu$$


权重之和为一，因为分母是归一化项。我们引入一个新的项 $K=W_1$，得到：

$$\begin{aligned}
\mu &= K \mu_z + (1-K) \bar\mu\\
&= \bar\mu + K(\mu_z - \bar\mu)
\end{aligned}$$

其中

$$K = \frac {\bar\sigma^2}{\bar\sigma^2 + \sigma_z^2}$$

$K$ 是*卡尔曼增益*。它是卡尔曼滤波器的关键。它是一个缩放项，用来在 $\mu_z$ 和 $\bar\mu$ 之间选取一个值。

让我们算几个例子。如果测量值比先验准确九倍，那么 $\bar\sigma^2 = 9\sigma_z^2$，并且

$$\begin{aligned}
\mu&=\frac{9 \sigma_z^2 \mu_z + \sigma_z^2\, \bar\mu} {9 \sigma_z^2 + \sigma_\mathtt{z}^2} \\
&= \left(\frac{9}{10}\right) \mu_z + \left(\frac{1}{10}\right) \bar\mu
\end{aligned}
$$

因此 $K = \frac 9 {10}$，要形成后验，我们取十分之九的测量值和十分之一的先验。

如果测量值和先验同样准确，那么 $\bar\sigma^2 = \sigma_z^2$，并且

$$\begin{gathered}
\mu=\frac{\sigma_z^2\,  (\bar\mu + \mu_z)}{2\sigma_\mathtt{z}^2} \\
= \left(\frac{1}{2}\right)\bar\mu + \left(\frac{1}{2}\right)\mu_z
\end{gathered}$$

这就是两个均值的平均值。取两个同样准确的值的平均，在直觉上是说得通的。

我们还可以用卡尔曼增益来表示方差：

$$\begin{aligned}
\sigma^2 &= \frac{\bar\sigma^2 \sigma_z^2 } {\bar\sigma^2 + \sigma_z^2} \\
&= K\sigma_z^2 \\
&= (1-K)\bar\sigma^2
\end{aligned}$$

我为什么把它写成这种形式，又为什么选了这些糟糕的变量名？有几个相关的原因。大多数书籍和论文都以这种形式给出卡尔曼滤波器。我从贝叶斯原理出发推导滤波器的做法并非无人知晓，但用得远没有那么多。其他的推导自然会导向这种形式的方程。此外，多元卡尔曼滤波器的方程看起来与这些方程几乎一模一样。所以，你需要学习并理解它们。

`z`、`P`、`Q` 和 `R` 这些名字是从哪里来的？在本书的其余部分你会看到它们被使用。在文献中，$R$ 几乎普遍用于表示测量噪声，$Q$ 用于表示过程噪声，$P$ 用于表示状态的方差。用 $z$ 表示测量值很常见，尽管并不普遍。你读到的几乎每一本书和每一篇论文都会用这些变量名。请习惯它们。

这也是思考滤波的一种强大方式。这是我们对 g-h 滤波器进行推理的方式。它强调取残差 $y = \mu_z - \bar\mu$，把卡尔曼增益求为我们对先验和测量值的不确定性之比 $K = P/(P+R)$，并通过把 $Ky$ 加到先验上来计算后验。

在这种形式中，贝叶斯的一面被掩盖了，“我们是在把似然乘以先验”这一事实也同样被掩盖了。两种观点是等价的，因为数学是相同的。我选择贝叶斯方法，是因为我认为它能给出对概率推理更直观而又深入的理解。这种使用 $K$ 的替代形式，则能让人深入理解所谓的*正交投影*方法。卡尔曼博士发明这个滤波器时用的是那种推导，而不是贝叶斯推理。在接下来的几章你会对此有更多了解。

## 算法的完整描述

回想一下我们用于 g-h 滤波器的图：
<img src="./figs/residual_chart.png">
=====CELL 56=====
我们在本章中一直在做同样的事情。卡尔曼滤波器做出预测，取一个测量值，然后在两者之间的某处形成新的估计。

**理解这一点极其重要**：本书中的每个滤波器实现的都是同一个算法，只是数学细节不同。在后面的章节中数学可能会变得有挑战性，但这个思想很容易理解。

重要的是要看穿某个特定滤波器方程的细节，理解这些方程在计算*什么*以及*为什么*。滤波器的数量极其庞大。它们都用不同的数学来实现同一个算法。数学的选择会影响结果的质量和可以表示的问题，但不会影响其背后的思想。

这是通用算法：

**初始化**

    1. Initialize the state of the filter
    2. Initialize our belief in the state

**预测**

    1. Use system behavior to predict state at the next time step
    2. Adjust belief to account for the uncertainty in prediction

**更新**

    1. Get a measurement and associated belief about its accuracy
    2. Compute residual between estimated state and measurement
    3. Compute scaling factor based on whether the measurement
    or prediction is more accurate
    4. set state between the prediction and measurement based
    on scaling factor
    5. update belief in the state based on how certain we are
    in the measurement

你很难找到一个不符合这种形式的贝叶斯滤波算法。有些滤波器不会包含某些方面，比如预测中的误差，另一些则有非常复杂的计算方法，但它们做的都是这些。

一元卡尔曼滤波器的方程是：

<u>预测</u>

$\begin{array}{|l|l|l|}
\hline
\text{Equation} & \text{Implementation} & \text{Kalman Form}\\
\hline
 \bar x = x + f_x & \bar\mu = \mu + \mu_{f_x} & \bar x = x + dx\\
& \bar\sigma^2 = \sigma^2 + \sigma_{f_x}^2 & \bar P = P + Q\\
\hline
\end{array}$


<u>更新</u>

$\begin{array}{|l|l|l|}
\hline
\text{Equation} & \text{Implementation}& \text{Kalman Form}\\
\hline
 x = \| \mathcal L\bar x\| & y = z - \bar\mu & y = z - \bar x\\
 & K = \frac {\bar\sigma^2} {\bar\sigma^2 + \sigma_z^2} & K = \frac {\bar P}{\bar P+R}\\
 & \mu = \bar \mu + Ky & x = \bar x + Ky\\
 & \sigma^2 = \frac {\bar\sigma^2 \sigma_z^2} {\bar\sigma^2 + \sigma_z^2} & P = (1-K)\bar P\\
\hline
\end{array}$

## 与 g-h 滤波器和离散贝叶斯滤波器的比较

现在是理解这三种滤波器在误差建模方式上有何不同的好时机。对于 g-h 滤波器，我们把测量值建模为这张图所示的样子：
=====CELL 59=====
传感器 A 返回的测量值是 160，传感器 B 返回 170。这些条是[*误差条*](https://en.wikipedia.org/wiki/Error_bar)——它们表示测量值可能的误差范围。因此，A 所测量的实际值可以在 157 到 163 之间，B 所测量的值在 161 到 179 之间。

当时我没有定义它，但这是一个[*均匀分布*](https://en.wikipedia.org/wiki/Uniform_distribution_(continuous&#41;)。均匀分布给范围内的任何事件分配相等的概率。根据这个模型，传感器 A 读到 157、160 或 163 的可能性相同。这些范围之外的任何值的概率为 0。

我们可以用高斯分布来对这种情形建模。我将对传感器 A 使用 $\mathcal{N}(160, 3^2)$，对传感器 B 使用 $\mathcal{N}(170, 9^2)$。我在下面把它们与均匀分布的误差条一起绘制出来以作比较。
=====CELL 61=====
使用均匀分布还是高斯分布是一种建模选择。两者都不能精确描述现实。在大多数情况下，高斯分布更真实。大多数传感器更可能返回接近被测值的读数，而不太可能返回远离该值的读数。高斯分布对这种倾向建模。相比之下，均匀分布假定范围内的任何测量值的可能性都相同。

现在让我们来看离散贝叶斯滤波器中使用的*离散分布*。这个模型把可能值的范围划分为离散的区间，并给每个区间分配一个概率。只要概率之和为一，这种分配可以完全任意。

让我们用均匀分布、高斯分布和离散分布来绘制一个传感器的数据。
=====CELL 63=====
我用随机数来形成离散分布，以说明它可以对任何任意的概率分布建模。这赋予了它巨大的威力。只要有足够多的离散区间，我们就可以对任何传感器的误差特性建模，无论多么复杂。但这种威力伴随着数学上的难以处理。把高斯分布相乘或相加只需要两行数学，结果仍是高斯分布。这种规律性使我们能够对滤波器的性能和行为进行强有力的分析。把离散分布相乘或相加需要对数据进行循环，而且我们没有简单的方法来刻画结果。分析基于离散分布的滤波器的性能特征极其困难，甚至不可能。

这里没有“正确”的选择。在本书后面我们会介绍*粒子滤波器*，它使用离散分布。它是一种极其强大的技术，因为它能处理任意复杂的情形。其代价是性能缓慢，并且难以进行解析分析。

现在我们先忽略这些问题，在接下来的几章中回到使用高斯分布。随着学习的推进，你会了解在数学模型中使用高斯分布的优点和局限。

规格表就是字面意思——规格。任何一个具体的传感器都会由于正常的制造差异而表现出不同的性能。这些值往往是最大值——规格是对性能至少达到这个水平的保证。如果你买一台昂贵的设备，它通常会附带一张纸，上面显示你这件具体产品的测试结果；这通常非常可信。另一方面，如果这是个廉价的传感器，很可能它在出售前几乎没有经过测试。制造商通常只测试其产出的一小部分子集，以验证样品落在期望的性能范围内。如果你有关键的应用，就需要仔细阅读规格表，弄清楚他们的范围到底是什么意思。他们保证的数字是最大值，还是比如说 $3\sigma$ 的误差率？是否每件产品都经过测试？方差是正态的，还是其他某种分布？最后，制造并不完美。你的元件可能有缺陷，与规格表上的性能不符。

例如，我正在看一份气流传感器的数据手册。其中有一个字段*重复性*，值为 $\pm 0.50\%$。这是高斯的吗？有偏差吗？例如，也许重复性在低温下几乎为 $0.0\%$，而在高温下总是接近 $+0.50\%$。电气元件的数据手册通常包含一节“典型性能特性”。这些用来记录难以在表格中轻易传达的信息。例如，我正在看一张 LM555 定时器的输出电压与电流关系的图表。图上有三条曲线，显示不同温度下的性能。响应在理想情况下是线性的，但这三条线都是弯曲的。这说明电压输出的误差很可能不是高斯的——对这款芯片来说，温度越高输出电压越低，而且如果输入电流很高，电压输出会非常非线性。

正如你可能猜到的，对传感器的性能建模是创建性能良好的卡尔曼滤波器时较困难的部分之一。

## 固定增益滤波器

嵌入式计算机通常处理器能力极其有限。许多计算机没有浮点电路。这些简单的方程可能给芯片带来沉重的负担。随着技术的进步，这种情况已经不那么严重了，但当你要购买数百万个处理器时，不要低估每个处理器省下一美元的价值。

在上面的例子中，滤波器的方差收敛到了一个固定值。只要测量和过程的方差是常数，这就总会发生。你可以利用这一点，通过运行模拟来确定方差收敛到什么值。然后你可以把这个值硬编码到你的滤波器中。只要你把滤波器初始化为一个好的起始猜测（我建议用第一个测量值作为初始值），滤波器就会表现得非常好。例如，狗的跟踪滤波器可以简化为这样：

```python
def update(x, z):
    K = .13232  # experimentally derived Kalman gain
    y = z - x   # residual
    x = x + K*y # posterior
    return x

def predict(x):
    return x + vel*dt
```

我使用了卡尔曼增益形式的更新函数，以强调我们完全不需要考虑方差。如果方差收敛到单个值，卡尔曼增益也是如此。

## FilterPy 的实现

FilterPy 实现了 `predict()` 和 `update()`。它们不仅适用于本章发展的一元情形，也适用于我们在后续章节中学习的更一般的多元情形。因此它们的接口略有不同。它们不是把高斯分布当作元组来接收，而是当作两个分开命名的变量。

`predict()` 接受几个参数，但我们只需要用到这四个：

```python
predict(x, P, u, Q)
```

`x` 是系统的状态。`P` 是系统的方差。`u` 是过程带来的移动量，`Q` 是过程中的噪声。调用 `predict()` 时你需要使用具名参数，因为大多数参数是可选的。`predict()` 的第三个参数**不是** `u`。

这些可能会让你觉得是糟糕的变量名。确实如此！正如我已经提到的，它们来自控制理论的悠久历史，你读到的每一篇论文或每一本书都会使用这些名字。所以，我们只能习惯它们。拒绝记住它们意味着你永远无法阅读文献。

## 总结

我们在本章中描述的卡尔曼滤波器是我们接下来要学习的更一般滤波器的一个特殊的、受限的情形。大多数教材不讨论这种一维形式。然而，我认为它是一块至关重要的垫脚石。我们从 g-h 滤波器开始这本书，然后实现了离散贝叶斯滤波器，现在实现了一维卡尔曼滤波器。我试图向你展示，这些滤波器中的每一个都使用相同的算法和推理。我们即将学习的卡尔曼滤波器的数学相当复杂，很难理解滤波器背后的简单性。这种复杂性带来了显著的好处：广义的滤波器将明显优于本章中的滤波器。

本章需要花时间来消化。要真正理解它，你可能需要把本章过好几遍。我鼓励你改变代码中的各种常数并观察结果。让你自己相信高斯分布是对走廊里狗的位置、天空中飞机的位置或化学反应室温度这类单峰置信度的良好表示。然后让你自己相信，把高斯分布相乘确实能根据你的先验置信度和新的测量值计算出新的置信度。最后，让你自己相信，如果你测量的是运动，把高斯分布相加就会更新你的置信度。

最重要的是，在**算法的完整描述**一节上多花些时间，确保你理解这个算法及其与 g-h 滤波器和离散贝叶斯滤波器的关系。这里只有一个“技巧”——在预测和测量值之间选取一个值。每个算法用不同的数学来执行这个技巧，但都使用相同的逻辑。
