## 动机

问题是这样的。我们有一些想要跟踪的运动物体。也许这些物体是战斗机和导弹，也许我们在跟踪在田野里打板球的人。这并不重要。我们学过的滤波器中，哪一个能处理这个问题？不幸的是，没有一个是理想的。让我们想想这个问题的特征。

* **多峰**：我们想同时跟踪零个、一个或多个物体。

* **遮挡**：一个物体可能遮住另一个物体，导致多个物体只有一个测量值。

* **非线性行为**：飞机会被风吹得颠簸，球沿抛物线运动，人们会相互碰撞。

* **非线性测量**：雷达给我们到物体的距离。把它转换成 (x,y,z) 坐标需要平方根，这是非线性的。

* **非高斯噪声：**当物体在背景前移动时，计算机视觉可能把背景的一部分误认为物体。

* **连续：**物体的位置和速度（即状态空间）可以随时间平滑变化。

* **多元**：我们想跟踪多个属性，例如位置、速度、转弯率等。

* **未知的过程模型**：我们可能不知道系统的过程模型。

我们学过的滤波器没有一个能在所有这些约束下良好工作。

* **离散贝叶斯滤波器**：它具备大部分属性。它是多峰的，可以处理非线性测量，并且可以扩展以处理非线性行为。然而，它是离散的且一元的。

* **卡尔曼滤波器**：卡尔曼滤波器对具有高斯噪声的单峰线性系统产生最优估计。这些条件在我们的问题中都不成立。

* **无迹卡尔曼滤波器**：UKF 处理非线性、连续、多元的问题。然而，它不是多峰的，也不能处理遮挡。它可以处理适度非高斯的噪声，但对于非常非高斯的分布或非线性很强的问题表现不佳。

* **扩展卡尔曼滤波器**：EKF 与 UKF 有相同的优点和局限，只是它对强非线性和非高斯噪声更加敏感。

## 蒙特卡洛采样

在 UKF 一章中，我生成了一幅类似这样的图，以说明非线性系统对高斯分布的影响：
=====CELL 7=====
左图显示 3,000 个点，它们按高斯分布正态分布

$$\mu = \begin{bmatrix}0\\0\end{bmatrix},\, \, \, \Sigma = \begin{bmatrix}32&15\\15&40\end{bmatrix}$$

右图显示这些点通过这组方程之后的结果：

$$\begin{aligned}x&=x+y\\
y &= 0.1x^2 + y^2\end{aligned}$$

使用有限个随机采样的点来计算结果称为[*蒙特卡洛*](https://en.wikipedia.org/wiki/Monte_Carlo_method) (MC) 方法。思路很简单。生成足够多的点，得到问题的代表性样本，让这些点通过你正在建模的系统，然后对变换后的点计算结果。

简而言之，这就是粒子滤波所做的事情。我们在全书中一直使用的贝叶斯滤波器算法被应用于成千上万个粒子，其中每个粒子代表系统的一个*可能的*状态。我们利用粒子的加权统计量，从成千上万个粒子中提取估计的状态。

## 通用粒子滤波器算法

1. **随机生成一批粒子**

  粒子可以有位置、航向，和/或你需要估计的任何其他状态变量。每个粒子有一个权重（概率），表示它与系统实际状态匹配的可能性有多大。以相同的权重初始化每个粒子。

2. **预测粒子的下一个状态**

 根据你预测真实系统的行为方式来移动粒子。

3. **更新**

  根据测量值更新粒子的权重。与测量值紧密匹配的粒子，权重高于与测量值匹配得不太好的粒子。

4. **重采样**

  丢弃极不可能的粒子，用更可能的粒子的副本替换它们。

5. **计算估计**

  可选地，计算这组粒子的加权均值和协方差，得到状态估计。

这个朴素的算法存在实际困难，我们需要克服，但这是总体思路。让我们看一个例子。我为 UKF 和 EKF 章节中的机器人定位问题编写了一个粒子滤波器。机器人有转向和速度控制输入。它有测量到可见地标距离的传感器。传感器和控制机构都有噪声，我们需要跟踪机器人的位置。

## 通过蒙特卡洛得到概率分布

假设我们想知道曲线 $y= \mathrm{e}^{\sin(x)}$ 在区间 [0, $\pi$] 下的面积。面积用定积分 $\int_0^\pi  \mathrm{e}^{\sin(x)}\, \mathrm{d}x$ 计算。作为练习，请尽管去求答案；我等着。

如果你聪明，就不会接受这个挑战；$\mathrm{e}^{\sin(x)}$ 无法解析地积分。世界上充满了我们无法积分的方程。例如，考虑计算一个物体的亮度。物体反射照射到它上面的一些光。一些反射光会从其他物体上反弹，重新照射到原来的物体上，增加了亮度。这就产生了一个*递归积分*。祝你好运。

然而，用蒙特卡洛技术计算积分是轻而易举的。要求曲线下的面积，先创建一个包含所需区间内曲线的边界框。在框内生成随机位置的点，并计算落在曲线下的点数与总点数之比。例如，如果 40% 的点在曲线下，边界框的面积是 1，那么曲线下的面积约为 0.4。当点数趋于无穷时，你可以达到任意精度。在实践中，几千个点就能给你相当准确的结果。

你可以用这种技术对任何难度任意的函数做数值积分，包括不可积的和不连续的函数。这种技术是 Stanley Ulam 在洛斯阿拉莫斯国家实验室发明的，让他能够对在纸面上无法求解的核反应进行计算。

让我们通过求圆的面积来计算 $\pi$。我们定义一个半径为 1 的圆，并用一个正方形把它框起来。正方形的边长为 2，所以面积为 4。我们在框内生成一组均匀分布的随机点，并数出有多少落在圆内。圆的面积计算为框的面积乘以圆内点数与总点数之比。最后，我们知道 $A = \pi r^2$，所以我们计算 $\pi = A / r^2$。

我们从创建点开始。

```python
N = 20000
pts = uniform(-1, 1, (N, 2))
```

如果一个点到圆心的距离小于或等于半径，它就在圆内。我们用 `numpy.linalg.norm` 计算距离，它计算向量的模。由于向量从 (0, 0) 开始，调用 norm 将计算该点到原点的距离。

```python
dist = np.linalg.norm(pts, axis=1)
```

接下来我们计算这些距离中哪些满足条件。这段代码返回一个布尔数组，如果满足条件 `dist <= 1` 则包含 `True`：

```python
in_circle = dist <= 1
```

剩下的就是数出圆内的点，计算 pi，并绘制结果。我把它们全放在一个单元里，这样你就可以对点数 `N` 尝试其他的值。

## 粒子滤波器

所有这些把我们带到了粒子滤波器。考虑在城市环境中跟踪一个机器人或一辆汽车。为保持一致，我将使用 EKF 和 UKF 章节中的机器人定位问题。在这个问题中，我们跟踪一个带有传感器的机器人，传感器测量到已知地标的距离和方位。

粒子滤波器是一族算法。我给出的是一种特定形式的粒子滤波器，它易于直观把握，并且与我们在本书中研究过的问题相关。这会让其中几个步骤显得有点“神奇”，因为我还没有给出完整的解释。那将在本章稍后给出。

根据上一节讨论所得的洞见，我们从创建几千个*粒子*开始。每个粒子有一个位置，代表对机器人在场景中所处位置的一种可能的置信度，也许还有航向和速度。假设我们对机器人的位置一无所知。我们会想把粒子均匀地散布在整个场景中。如果把所有粒子看作表示一个概率分布，粒子较多的位置表示较高的置信度，粒子较少的位置表示较低的置信度。如果在某个特定位置附近有一大簇粒子，就意味着我们更确定机器人在那里。

每个粒子需要一个权重——理想情况下是它代表机器人真实位置的概率。这个概率很少能计算，所以我们只要求它与这个可计算的概率*成正比*。在初始化时，我们没有理由偏爱某个粒子，所以对 $N$ 个粒子，我们分配权重 $1/N$。我们使用 $1/N$，使所有概率之和等于一。

粒子和权重的组合构成了我们问题的*概率分布*。回想*离散贝叶斯*一章。在那一章中，我们把走廊中的位置建模为离散且均匀间隔的。这里非常相似，只是粒子随机分布在连续空间中，而不是被限制在离散的位置上。在这个问题中，机器人可以在某个任意尺寸的平面上移动，右下角在 (0,0)。

要跟踪我们的机器人，我们需要维护 x、y 和航向的状态。我们将在一个形状为 `(N, 3)` 的数组中存储 `N` 个粒子。三列依次包含 x、y 和航向。

如果你在被动地跟踪某个东西（没有控制输入），那么你需要把速度包含在状态中，并用该估计来做预测。更多的维度需要指数级更多的粒子才能形成良好的估计，所以我们总是尝试最小化状态中随机变量的数量。

### 预测步骤

贝叶斯算法中的预测步骤使用过程模型来更新对系统状态的置信度。我们如何用粒子做到这一点？每个粒子代表机器人的一个可能位置。假设我们给机器人发送命令，让它移动 0.1 米，同时转过 0.007 弧度。我们可以把每个粒子移动这么多。如果这样做，我们很快就会遇到一个问题。机器人的控制并不完美，所以它不会完全按指令移动。因此，我们需要给粒子的运动添加噪声，才有合理的机会捕捉到机器人的实际运动。如果你不对系统中的不确定性建模，粒子滤波器就不能正确地对我们对机器人位置的置信度的概率分布建模。
=====CELL 26=====
### 更新步骤

接下来我们得到一组测量值——每个当前可见的地标一个。应该如何使用这些测量值来改变由粒子建模的概率分布？

回想**离散贝叶斯**一章。在那一章中，我们把走廊中的位置建模为离散且均匀间隔的。我们给每个位置分配一个概率，称为*先验*。当新的测量值到来时，我们把该位置的当前概率（*先验*）乘以测量值与该位置匹配的*似然*：

```python
def update(likelihood, prior):
    posterior = prior * likelihood
    return normalize(posterior)
```

这是下面这个方程的实现

$$x = \| \mathcal L \bar x \|$$

而它是贝叶斯定理的一种实现：

$$\begin{aligned}P(x \mid z) &= \frac{P(z \mid x)\, P(x)}{P(z)} \\
 &= \frac{\mathtt{likelihood}\times \mathtt{prior}}{\mathtt{normalization}}\end{aligned}$$
=====CELL 27=====
我们对粒子做同样的事情。每个粒子有一个位置和一个权重，权重估计它与测量值的匹配程度。对权重做归一化使它们之和为一，就把它们变成了概率分布。离机器人最近的粒子通常比远离机器人的粒子权重更高。
=====CELL 29=====
在文献中，算法的这一部分称为*序贯重要性采样*，简称 SIS。权重的方程称为*重要性密度*。我会在后面的一节给出这些理论基础。现在我希望它在直觉上说得通。如果我们根据粒子与测量值的匹配程度给它们加权，那么它们很可能是纳入测量值之后系统概率分布的良好样本。理论证明确实如此。权重就是贝叶斯定理中的*似然*。不同的问题需要以略有不同的方式处理这一步，但这是总体思路。

### 计算状态估计

在大多数应用中，你会想在每次更新之后知道估计的状态，但滤波器只由一组粒子构成。假设我们在跟踪一个物体（即它是单峰的），我们可以把估计的均值计算为粒子加权值之和。

$$\displaystyle \mu = \frac{1}{N}\sum_{i=1}^N w^ix^i$$

这里我采用记号 $x^i$ 表示第 $\mathtt{i}^{th}$ 个粒子。使用上标是因为我们常常需要用下标表示时间步，例如第 $\mathtt{k+1}^{th}$ 个时间步会得到笨拙的 $x^i_{k+1}$。

### 粒子重采样

SIS 算法存在*退化问题*。它从权重相等的均匀分布粒子开始。机器人附近可能只有少数几个粒子。随着算法运行，任何与测量值不匹配的粒子都会获得极低的权重。只有靠近机器人的粒子才会有可观的权重。我们可能有 5,000 个粒子，却只有 3 个对状态估计有实质性贡献！我们说滤波器*退化*了。这个问题通常通过某种形式的粒子*重采样*来解决。

权重非常小的粒子不能有意义地描述机器人的概率分布。重采样算法丢弃概率很低的粒子，并用概率更高的新粒子替换它们。它是通过复制相对高概率的粒子来做到这一点的。这些副本被预测步骤中加入的噪声略微分散。这就得到一组点，其中绝大多数粒子准确地表示了概率分布。

有许多重采样算法。现在让我们看最简单的一种，*简单随机重采样*，也称*多项式重采样*。它从当前粒子集中采样 $N$ 次，用样本构成一组新粒子。选中任何给定粒子的概率应该与它的权重成正比。

我们用 NumPy 的 `cumsum` 函数来做到这一点。`cumsum` 计算数组的累积和。也就是说，元素一是元素零和一之和，元素二是元素零、一和二之和，依此类推。然后我们生成 0.0 到 1.0 范围内的随机数，并做二分查找，找到与该数最接近的权重：

```python
mu, var = estimate(particles, weights)
```

第一行预测粒子的位置，假设机器人沿直线移动 (`u[0] == 0`)，并在 x 轴和 y 轴上各移动 1 个单位 (`u[1]==1.414`)。转向误差的标准差是 0.2，距离的标准差是 0.05。当这个调用返回时，粒子都已经向前移动了，但权重不再正确，因为还没有更新。

下一行把测量值纳入滤波器。这不会改变粒子的位置，只会改变权重。如果你还记得，粒子的权重被计算为它与传感器误差模型的高斯分布匹配的概率。粒子离测得的距离越远，它越不可能是一个好的表示。

最后两行检查有效粒子数 ($\hat{N}_\text{eff})$。如果它低于 $N/2$，我们就执行重采样，以尽量确保我们的粒子对实际概率分布形成良好的表示。

现在让我们把所有粒子都绘制出来看看。以交互方式看到这一过程发生更有启发性，但这种格式仍然给我们有用的信息。我用非常浅的绿色和大圆圈绘制了原始的随机点分布，以帮助区分它们与后续迭代（其中粒子用黑色像素绘制）。粒子数量之多使得难以看清细节，所以我把迭代次数限制为 8，这样我们就可以放大并更仔细地观察。
=====CELL 45=====
从图上看，在机器人的前两个位置似乎只有几个粒子。事实并非如此；有 5,000 个粒子，但由于重采样，大多数是彼此的副本。原因是传感器的高斯分布非常窄。这称为*样本贫化*，可能导致滤波器发散。我会在下面详细讨论。现在，看 x=2 处的第二步，我们可以看到粒子已经有所分散。这种分散是由运动模型噪声造成的。所有粒子都根据控制输入 `u` 向前投影，但每个粒子上加的噪声与机器人控制机构的误差成正比。到第三步时，粒子已经分散到足以在机器人周围形成令人信服的粒子云。

粒子云的形状是椭圆。这不是巧合。传感器和机器人控制都被建模为高斯的，所以系统的概率分布也是高斯的。粒子滤波器是对概率分布的采样，所以粒子云应该是椭圆。

重要的是要认识到，粒子滤波器算法*并不要求*传感器或系统是高斯的或线性的。因为我们用粒子云表示概率分布，所以我们可以处理任何概率分布和强非线性问题。概率模型中可以有不连续性和硬性限制。
=====CELL 46=====
### 传感器误差对滤波器的影响

滤波器最初的几次迭代产生了许多重复的粒子。发生这种情况是因为传感器的模型是高斯的，而我们给了它一个小的标准差 $\sigma=0.1$。乍一看这是违反直觉的。噪声越小，卡尔曼滤波器表现越好，但粒子滤波器的表现可能更差。


我们可以推断为什么会这样。如果 $\sigma=0.1$，机器人在 (1, 1)，一个粒子在 (2, 2)，那么这个粒子距离机器人有 14 个标准差。这使它的概率接近零。它对均值的估计毫无贡献，而且在重采样之后极不可能存活。如果 $\sigma=1.4$，那么粒子只有 $1\sigma$ 远，因此它会对均值的估计有所贡献。在重采样期间，它很可能被复制一次或多次。

这一点*非常重要*，需要理解——非常准确的传感器可能导致滤波器性能不佳，因为很少有粒子是概率分布的良好样本。我们有几种解决办法。第一，我们可以人为地增大传感器噪声的标准差，这样粒子滤波器就会接受更多的点作为与机器人概率分布匹配。这不是最优的，因为其中一些点匹配得很差。真正的问题是生成的点不够多，无法使足够多的点靠近机器人。增大 `N` 通常能解决这个问题。这个决定不是没有代价的，因为增加粒子数会显著增加计算时间。尽管如此，让我们看看使用 100,000 个粒子的结果。

在 x=1 处有多得多的粒子，在 x=2 处我们有了令人信服的粒子云。显然滤波器表现得更好，但代价是大量的内存使用和很长的运行时间。

另一种方法是更聪明地生成初始粒子云。假设我们猜测机器人在 (0, 0) 附近。这并不精确，因为模拟实际上把机器人放在 (1, 1)，但它很接近。如果我们在 (0, 0) 附近创建一个正态分布的粒子云，粒子与机器人位置匹配的机会就大得多。

## 重要性采样

我轻描淡写地绕过了一个困难，现在我们必须面对它。存在某个描述我们机器人位置和运动的概率分布。我们想从该分布中抽取粒子样本，并用 MC 方法计算积分。

我们的困难在于，在许多问题中我们不知道这个分布。例如，被跟踪的物体的移动方式可能与我们用状态模型预测的非常不同。我们如何从未知的概率分布中抽取样本？

统计学中有一个称为[*重要性采样*](https://en.wikipedia.org/wiki/Importance_sampling)[1]的定理。了不起的是，它给了我们一种从另一个已知的概率分布中抽取样本，并用它们来计算未知分布的性质的方法。这是一个奇妙的定理，让我心中充满喜悦。

思路很简单，而且我们已经用过它了。我们从已知的概率分布中抽取样本，但根据我们感兴趣的分布对*样本加权*。然后我们可以通过计算样本的加权均值和加权方差来计算均值和方差等性质。

对于机器人定位问题，我们从由状态模型预测步骤计算出的概率分布中抽取样本。换句话说，我们推理：“机器人在那里，它也许以这个方向和速度运动，因此它可能在这里”。然而，机器人可能做了完全不同的事情。它可能掉下了悬崖，或者被迫击炮弹击中。在每种情况下，概率分布都不正确。看起来我们被难住了，但其实没有，因为我们可以使用重要性采样。我们从那个很可能不正确的概率分布中抽取粒子，然后根据粒子与测量值的匹配程度给它们加权。这种加权是基于真实的概率分布的，所以根据理论，得到的均值、方差等将是正确的！

这怎么可能是真的？我会给你数学；如果你不打算超越机器人定位问题，可以放心地跳过这一部分。然而，其他粒子滤波器问题需要不同的重要性采样方法，一点数学会有帮助。而且，文献和网上的许多内容都使用数学表述，而不是我相当不精确的“想象一下……”式的阐述。如果你想理解文献，就需要知道下面的方程。

我们有某个概率分布 $\pi(x)$，想从中取样。然而，我们不知道 $\pi(x)$ 是什么；相反，我们只知道另一个概率分布 $q(x)$。在机器人定位的语境中，$\pi(x)$ 是机器人的概率分布，但我们不知道它，而 $q(x)$ 是我们测量值的概率分布，这是我们知道的。

函数 $f(x)$ 在概率分布 $\pi(x)$ 下的期望值是

$$\mathbb{E}\big[f(x)\big] = \int f(x)\pi(x)\, dx$$

我们不知道 $\pi(x)$，所以无法计算这个积分。我们知道另一个分布 $q(x)$，所以可以在不改变值的情况下把它加入积分

$$\mathbb{E}\big[f(x)\big] = \int f(x)\pi(x)\frac{q(x)}{q(x)}\, dx$$

现在我们重新排列并分组各项

$$\mathbb{E}\big[f(x)\big] = \int f(x)q(x)\, \,  \cdot \,  \frac{\pi(x)}{q(x)}\, dx$$

$q(x)$ 对我们是已知的，所以我们可以用 MC 积分计算 $\int f(x)q(x)$。剩下的是 $\pi(x)/q(x)$。这是一个比值，我们把它定义为*权重*。这给出

$$\mathbb{E}\big[f(x)\big] = \sum\limits_{i=1}^N f(x^i)q(x^i)w(x^i)$$

也许这看起来有点抽象。如果我们想计算粒子的均值，我们会计算

$$\mu = \frac{1}{N}\sum\limits_{i=1}^N x^iw^i$$

这就是我在本章前面给你的方程。

要求权重与比值 $\pi(x)/q(x)$ 成正比。我们通常不知道确切的值，所以在实践中我们通过除以 $\sum w(x^i)$ 对权重做归一化。

当你构建粒子滤波器算法时，你将不得不根据你所处情形的具体情况来实现这一步。对于机器人定位，$q(x)$ 的最佳分布是来自滤波器 `predict()` 步骤的粒子分布。让我们再看一遍代码：

```python
def update(particles, weights, z, R, landmarks):
    for i, landmark in enumerate(landmarks):
        dist = np.linalg.norm(particles[:, 0:2] - landmark, axis=1)
        weights *= scipy.stats.norm(dist, R).pdf(z[i])

    weights += 1.e-300      # avoid round-off to zero
    weights /= sum(weights) # normalize
```

这里我们基于贝叶斯计算 $\| \text{likelihood} \times \text{prior}\|$ 来计算权重

当然，如果你能根据先验计算出后验概率分布，你就应该这样做。如果你不能，那么重要性采样为你提供了一种解决这个问题的方法。在实践中，计算后验是极其困难的。卡尔曼滤波器之所以成为一个引人注目的成功，是因为它利用高斯分布的性质找到了解析解。一旦我们放宽卡尔曼滤波器所要求的条件（马尔可夫性质、高斯测量值和过程），重要性采样和蒙特卡洛方法就使问题变得易于处理。

## 重采样方法

重采样算法会影响滤波器的性能。例如，假设我们通过随机挑选粒子来重采样。这会导致我们选中许多权重很低的粒子，得到的粒子集会是问题概率分布的糟糕表示。

关于这个主题的研究仍在继续，但有少数几种算法在各种各样的情形下在实践中表现良好。我们希望算法具有几个性质。它应该优先选择概率更高的粒子。它应该选择高概率粒子的代表性群体，以避免样本贫化。它应该包含足够多的低概率粒子，使滤波器有机会检测到强非线性行为。

### 残差重采样

残差重采样既改善了多项式重采样的运行时间，又确保采样在粒子群体中是均匀的。它相当巧妙：把归一化的权重乘以 *N*，然后用每个权重的整数值来定义对该粒子取多少个样本。例如，如果一个粒子的权重是 0.0012，$N$=3000，那么缩放后的权重是 3.6，所以将对该粒子取 3 个样本。这确保所有较高权重的粒子至少被选中一次。运行时间是 $O(N)$，比多项式重采样更快。

然而，这并不能生成全部 *N* 个选择。要选出其余的，我们取*残差*：权重减去整数部分，剩下数的小数部分。然后我们使用更简单的采样方案，比如多项式方案，基于残差来选择其余的粒子。在上面的例子中，缩放后的权重是 3.6，所以残差是 0.6 (3.6 - int(3.6))。这个残差非常大，所以该粒子很可能被再次采样。这是合理的，因为残差越大，舍入误差越大，因此该粒子在整数步骤中相对采样不足。

=====CELL 81=====
多项式重采样的表现相当糟糕。有一个非常大的权重根本没有被采样。最大的权重只得到一次重采样，而最小的权重却被采样了两次。我读过的网上大多数教程都使用多项式重采样，我不确定为什么。多项式重采样在文献中或真实问题中很少使用。除非你有非常好的理由，否则我建议不要使用它。

残差重采样算法在它试图做的事情上做得非常出色：确保所有最大的权重都被重采样多次。它并没有把样本均匀地分布到各个粒子上——许多相当大的权重根本没有被重采样。

系统重采样和分层重采样都表现得非常好。系统采样在确保我们从粒子空间的所有部分采样的同时，也确保较大的权重按比例更常被重采样，做得非常出色。分层重采样不像系统重采样那么均匀，但在确保较高的权重被更多地重采样方面稍好一些。

关于这些算法的理论性能已经有很多文章，请随意阅读。在实践中，我把粒子滤波器应用于难以用解析方法处理的问题，所以我对某个具体分析对这些问题的有效性有些怀疑。在实践中，分层算法和系统算法在各种问题上都表现良好且相近。我说试一个，如果有效就继续用它。如果滤波器的性能至关重要，两个都试试，也许再看看有没有针对你的具体问题发表的文献，能给你更好的指导。

## 总结

本章只是触及了一个庞大主题的表面。我的目标不是教你这个领域，而是让你接触实用的贝叶斯蒙特卡洛滤波技术。

粒子滤波器是一种*集合*滤波。卡尔曼滤波器用高斯分布表示状态。测量值用贝叶斯定理作用于高斯分布，预测用状态空间方法完成。这些技术都作用于高斯分布——即概率分布。

相比之下，集合技术用一组离散的点及其相关概率来表示概率分布。测量值作用于这些点，而不是高斯分布。同样，系统模型作用于这些点，而不是高斯分布。然后我们计算得到的点集合的统计性质。

这些选择有许多权衡。卡尔曼滤波器非常高效，如果线性和高斯噪声的假设成立，它是最优估计器。如果问题是非线性的，我们就必须对问题线性化。如果问题是多峰的（跟踪多个物体），卡尔曼滤波器就无法表示。卡尔曼滤波器要求你知道状态模型。如果你不知道你的系统是如何运行的，性能就很差。

相比之下，粒子滤波器适用于任何任意的、非解析的概率分布。只要粒子集合足够大，就能形成分布的精确近似。即使存在严重的非线性，它的表现也很出色。重要性采样使我们即使不知道底层的概率分布也能计算概率。蒙特卡洛技术取代了其他滤波器所需的解析积分。

这种能力是有代价的。最明显的代价是滤波器给计算机带来的高计算和内存负担。不那么明显的是，它们很善变。你必须小心避免粒子退化和发散。证明你的滤波器的正确性可能非常困难。如果你在处理多峰分布，你还有进一步的工作要做，即对粒子聚类，以确定多个物体的路径。当物体彼此靠近时，这可能非常困难。

粒子滤波器有许多不同的类别；我只描述了朴素的 SIS 算法，随后是一个表现良好的 SIR 算法。滤波器有许多类别，每个类别中又有许多滤波器的例子。要把它们都描述一遍需要一本小书。

当你阅读关于粒子滤波器的文献时，你会发现它到处都是积分。我们用积分对概率分布进行计算，所以使用积分给作者们提供了强大而紧凑的记号。你必须认识到，当你把这些方程化为代码时，你将用粒子来表示分布，积分被对粒子求和所取代。如果你记住本章的核心思想，这些材料就不该令人生畏。
