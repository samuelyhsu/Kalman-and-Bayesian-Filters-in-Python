# 交互

这是一组交互演示，大部分来自本书。如果你阅读的是本书的印刷版，或是通过 Github 或 nbviewer 在线阅读，就无法运行这些交互。

所以我创建了这个 notebook。如果你的电脑上没有安装 IPython，可以按下面的方法运行交互。

1. 在浏览器中访问 try.juptyer.org。它会为你启动一个临时的 notebook 服务器。

2. 点击 **New** 按钮并选择 `Python 3`。这会创建一个新的 notebook，在你的浏览器中为你运行 Python 3。

3. 复制本 notebook 中某个单元格的全部内容，粘贴到浏览器中那个 notebook 的一个“code”单元格里。

4. 按 CTRL+ENTER 执行该单元格。

5. 尽情玩吧！修改代码。玩耍。实验。折腾。

你的服务器和 notebook 不会被永久保存。一旦关闭会话，你的数据就会丢失。是的，你按保存时它会提示正在保存文件，你也能在目录中看到它。但这只是发生在一个 Docker 容器中，窗口一关闭该容器就会被删除。请把你想保留的任何改动复制粘贴到外部文件中。

当然，如果你安装了 IPython，可以下载这个 notebook 并在自己的电脑上运行。在你下载该文件的目录中，在命令提示符下输入

    ipython notebook

然后点击该文件的名称将其打开。

# 试验 FPF'


卡尔曼滤波器在预测步骤中使用方程 $P^- = FPF^\mathsf{T}$ 来计算协方差矩阵的先验，其中 P 是协方差矩阵，F 是系统转移函数。对于牛顿系统 $x = \dot{x}\Delta t + x_0$，F 可能是这样的

$$F = \begin{bmatrix}1 & \Delta t\\0 & 1\end{bmatrix}$$

$FPF^\mathsf{T}$ 通过利用位置（$x$）与速度（$\dot{x}$）之间的相关性来改变 P。这个交互图让你看到 F 的不同设计对这个值有什么影响。例如：

* 如果 $x$ 与 $\dot{x}$ 不相关呢？（把 F01 设为 0）

* 如果 $x = 2\dot{x}\Delta t + x_0$ 呢？（把 F01 设为 2）

*  如果 $x = \dot{x}\Delta t + 2*x_0$ 呢？（把 F00 设为 2）

* 如果 $x = \dot{x}\Delta t$ 呢？（把 F00 设为 0）
